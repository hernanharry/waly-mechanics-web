# Fotos del taller

Colocá acá las imágenes reales con estos nombres exactos y la página las muestra sola
(mientras el archivo no exista, se ve el placeholder en la sección Galería / banners):

| Archivo            | Uso                                    |
| ------------------ | -------------------------------------- |
| `banner-logo.jpg`  | Banner horizontal del logo (portada)   |
| `flyer.jpg`        | Afiche vertical (junto al CTA final)   |
| `interior.jpg`     | Interior del taller (foto destacada)   |
| `local.jpg`        | Frente del local con el cartel         |
| `calle.jpg`        | Trabajo en la calle                    |
| `entrada.jpg`      | Entrada del taller de noche            |

Formato recomendado: JPG o WebP, ancho mínimo 1600 px, calidad ~80.
